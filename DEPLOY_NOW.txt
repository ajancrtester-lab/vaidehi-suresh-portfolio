2. Sign up with Google or Email
3. Create FREE M0 Cluster (choose AWS, nearest region)
4. Create database user:
   - Username: admin
   - Password: (generate strong password, SAVE IT!)
5. Network Access: Add IP → "Allow from anywhere" (0.0.0.0/0)
6. Get connection string:
   - Click "Connect" on your cluster
   - Choose "Connect your application"
   - Copy the connection string
   - Replace <password> with your actual password
   - Add database name at end: /portfolio_db

SAVE THIS CONNECTION STRING - YOU'LL NEED IT FOR RAILWAY!

Example:
mongodb+srv://admin:YOUR_PASSWORD@cluster0.xxxxx.mongodb.net/portfolio_db?retryWrites=true&w=majority

OPTION A: DRAG & DROP (Easiest - 5 min)
────────────────────────────────────────

1. Build frontend locally:
   
   cd /app/frontend
   export REACT_APP_BACKEND_URL=https://your-railway-url.railway.app
   yarn build

2. Go to: https://app.netlify.com/drop
3. Drag the /app/frontend/build folder to the upload area
4. Done! Your site is live.

OPTION B: GITHUB AUTO-DEPLOY (Recommended - 10 min)
──────────────────────────────────────────────────

1. Go to: https://app.netlify.com
2. Click "Add new site" → "Import an existing project"
3. Choose GitHub → Select your repository
4. Build settings:
   - Base directory: frontend
   - Build command: yarn build
   - Publish directory: frontend/build
5. Environment variables → Add:
   
   REACT_APP_BACKEND_URL=https://your-railway-url.railway.app

6. Click "Deploy site"

7. After deployment, get your Netlify URL:
   - It will be like: https://random-name-123.netlify.app
   - You can customize it in Site settings
